# AstroTarot MariaDB Database Setup Guide (Windows)

## Overview
This guide will help you set up and configure the MariaDB database for the AstroTarot website on Windows, replacing the existing JSON-based data storage with a more robust and scalable database solution.

## Prerequisites
- Windows 10 or Windows Server 2016+
- Administrator privileges on the machine
- Access to MariaDB command line or a database management tool (HeidiSQL, DBeaver, phpMyAdmin, etc.)
- Basic knowledge of SQL commands

## Installation Steps

### 1. Install MariaDB on Windows

#### Option A: Using the Official Installer (Recommended)
1. Download MariaDB from https://mariadb.org/download/
2. Select "Windows" and choose the latest stable version
3. Download the MSI installer package
4. Run the installer as Administrator
5. Follow the installation wizard:
   - Accept the license agreement
   - Choose "Typical" installation type
   - Set root password (remember this password!)
   - Enable "Install as service" and "Start service after installation"
   - Enable "Enable networking" (port 3306)
   - Enable "Use UTF8 as default charset"

#### Option B: Using Chocolatey (if you have Chocolatey installed)
```powershell
# Run PowerShell as Administrator
choco install mariadb
```

#### Option C: Using XAMPP/WAMP (if you prefer bundled solutions)
1. Download XAMPP from https://www.apachefriends.org/
2. Install XAMPP with MariaDB component
3. Start MariaDB from the XAMPP control panel

### 2. Secure MariaDB Installation on Windows

#### Option A: Using mysql_secure_installation (if available)
```cmd
# Open Command Prompt as Administrator
cd "C:\Program Files\MariaDB\bin"
mysql_secure_installation
```

#### Option B: Manual Security Setup (Recommended for Windows)
1. **Open MariaDB Command Line Client**:
   - Go to Start Menu → MariaDB → MariaDB Command Line Client
   - Or run: `"C:\Program Files\MariaDB\bin\mysql.exe" -u root -p`

2. **Set Root Password** (if not set during installation):
```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'YourStrongPasswordHere';
FLUSH PRIVILEGES;
```

3. **Remove Anonymous Users**:
```sql
DROP USER ''@'localhost';
DROP USER ''@'host_name';
FLUSH PRIVILEGES;
```

4. **Remove Test Database**:
```sql
DROP DATABASE IF EXISTS test;
FLUSH PRIVILEGES;
```

5. **Restrict Remote Root Access** (recommended for security):
```sql
DELETE FROM mysql.user WHERE User='root' AND Host NOT IN ('localhost', '127.0.0.1', '::1');
FLUSH PRIVILEGES;
```

6. **Reload Privileges**:
```sql
FLUSH PRIVILEGES;
```

### 3. Verify MariaDB Service

#### Check Service Status:
```cmd
# In Command Prompt as Administrator
sc query MariaDB
```

#### Start/Stop Service:
```cmd
# Start service
net start MariaDB

# Stop service
net stop MariaDB

# Restart service
net stop MariaDB && net start MariaDB
```

#### Set Service to Auto-start:
```cmd
sc config MariaDB start= auto
```

### 4. Create the Database

#### Option A: Using the Schema File (Recommended)
```cmd
# Open Command Prompt as Administrator
cd "C:\Users\antonia\Desktop\Website AstroTarot"

# Connect to MariaDB as root
"C:\Program Files\MariaDB\bin\mysql.exe" -u root -p

# Execute the schema file
source database/schema.sql;
```

#### Option B: Manual Setup
1. **Connect to MariaDB**:
```cmd
"C:\Program Files\MariaDB\bin\mysql.exe" -u root -p
```

2. **Create Database and User**:
```sql
-- Create database
CREATE DATABASE astrotarot_db CHARACTER SET utf8mb4 COLLATE utf8mb4_romanian_ci;

-- Create user
CREATE USER 'astrotarot_user'@'localhost' IDENTIFIED BY 'your_secure_password_here';

-- Grant privileges
GRANT SELECT, INSERT, UPDATE, DELETE ON astrotarot_db.* TO 'astrotarot_user'@'localhost';

-- Apply privileges
FLUSH PRIVILEGES;

-- Use the database
USE astrotarot_db;
```

3. **Run the remaining schema commands** from `database/schema.sql` manually or copy-paste them

### 5. Update Database Credentials

Create a `.env` file in the backend directory:
```env
# Database Configuration
DB_HOST=localhost
DB_PORT=3306
DB_NAME=astrotarot_db
DB_USER=astrotarot_user
DB_PASSWORD=your_secure_password_here

SMTP_FROM_EMAIL=your_email@gmail.com

```

## Database Structure

### Tables Overview:

1. **videos** - YouTube video information
   - Stores video titles, links, descriptions, publish dates
   - Categorized by zodiac sign and video type
   - Supports featured videos functionality

2. **zodiac_signs** - Zodiac sign information
   - Maps zodiac signs to their respective HTML pages
   - Stores element, symbol, and date range information

3. **bookings** - Consultation appointment bookings
   - Stores customer information and booking details
   - Tracks booking status and consultation dates

4. **tarot_cards** - Tarot card information
   - Stores all 22 Major Arcana cards
   - Includes meanings, keywords, and image references

5. **daily_messages** - Daily tarot messages
   - Tracks which card is featured each day
   - Allows for custom daily messages

6. **settings** - Website configuration
   - Stores site-wide settings and preferences

## Migration from JSON

### Current JSON Files Being Replaced:
- `js/videos.json` → `videos` table
- `js/zodiac.json` → `zodiac_signs` table
- Hardcoded tarot cards in `pages/messages/index.html` → `tarot_cards` table

### Benefits of Migration:
1. **Performance**: Faster queries and data retrieval
2. **Scalability**: Can handle much more data efficiently
3. **Security**: Better data protection and access control
4. **Maintenance**: Easier to update and manage data
5. **Features**: Advanced filtering, sorting, and searching

## Using the Database

### Common SQL Queries:

#### Get Latest Videos:
```sql
SELECT title, link, description, published_date 
FROM videos 
ORDER BY published_date DESC 
LIMIT 10;
```

#### Get Videos by Zodiac Sign:
```sql
SELECT title, link, description, published_date 
FROM videos 
WHERE zodiac_sign = 'Capricorn' 
ORDER BY published_date DESC;
```

#### Get Featured Videos:
```sql
SELECT title, link, description, published_date 
FROM videos 
WHERE featured = TRUE 
ORDER BY published_date DESC;
```

#### Get Daily Tarot Card:
```sql
SELECT tc.name, tc.description, tc.image_filename 
FROM daily_messages dm 
JOIN tarot_cards tc ON dm.card_id = tc.id 
WHERE dm.message_date = CURDATE() AND dm.is_active = TRUE;
```

#### Get Recent Bookings:
```sql
SELECT name, email, preferred_time, status, created_at 
FROM bookings 
ORDER BY created_at DESC 
LIMIT 20;
```

## PHP Integration

### Database Connection Class:
```php
<?php
class Database {
    private $host = 'localhost';
    private $dbname = 'astrotarot_db';
    private $username = 'astrotarot_user';
    private $password = 'your_secure_password_here';
    private $pdo;

    public function __construct() {
        $this->connect();
    }

    private function connect() {
        try {
            $this->pdo = new PDO(
                "mysql:host={$this->host};dbname={$this->dbname};charset=utf8mb4",
                $this->username,
                $this->password,
                [
                    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                    PDO::ATTR_EMULATE_PREPARES => false,
                ]
            );
        } catch (PDOException $e) {
            throw new Exception("Database connection failed: " . $e->getMessage());
        }
    }

    public function getConnection() {
        return $this->pdo;
    }
}
```

## Windows Backup and Maintenance

### Regular Backups:

#### Using Command Prompt:
```cmd
# Full backup
"C:\Program Files\MariaDB\bin\mysqldump.exe" -u root -p astrotarot_db > backup_%date:~-4,4%%date:~-10,2%%date:~-7,2%_%time:~0,2%%time:~3,2%%time:~6,2%.sql

# Compressed backup (requires 7-Zip or WinRAR)
"C:\Program Files\MariaDB\bin\mysqldump.exe" -u root -p astrotarot_db | "C:\Program Files\7-Zip\7z.exe" a -si backup_%date:~-4,4%%date:~-10,2%%date:~-7,2%.7z
```

#### Using Batch File (create backup.bat):
```batch
@echo off
set BACKUP_DIR=C:\DatabaseBackups
set TIMESTAMP=%date:~-4,4%%date:~-10,2%%date:~-7,2%_%time:~0,2%%time:~3,2%%time:~6,2%
set TIMESTAMP=%TIMESTAMP: =0%

if not exist "%BACKUP_DIR%" mkdir "%BACKUP_DIR%"

"C:\Program Files\MariaDB\bin\mysqldump.exe" -u root -p astrotarot_db > "%BACKUP_DIR%\backup_%TIMESTAMP%.sql"

echo Backup completed: "%BACKUP_DIR%\backup_%TIMESTAMP%.sql"
pause
```

#### Using Windows Task Scheduler:
1. Open Task Scheduler
2. Create Basic Task
3. Set trigger to "Daily" at your preferred time
4. Action: "Start a program"
5. Program: `C:\DatabaseBackups\backup.bat`

### Restore from Backup:
```cmd
"C:\Program Files\MariaDB\bin\mysql.exe" -u root -p astrotarot_db < backup_20260423_120000.sql
```

## Windows Troubleshooting

### Common Issues:

1. **Connection Failed**:
   - Check if MariaDB service is running: `sc query MariaDB`
   - Verify credentials in `.env` file
   - Check Windows Firewall settings for port 3306
   - Try connecting with HeidiSQL to test credentials

2. **Service Won't Start**:
   - Check Windows Event Viewer for MariaDB errors
   - Verify my.ini configuration file
   - Check disk space and permissions
   - Try starting service manually: `net start MariaDB`

3. **Character Encoding Issues**:
   - Ensure database and tables use `utf8mb4` charset
   - Check connection charset in PHP
   - Verify Windows regional settings

4. **Performance Issues**:
   - Run `EXPLAIN` on slow queries
   - Check if indexes are being used
   - Consider query optimization
   - Monitor Windows Task Manager for MariaDB resource usage

### Windows-Specific Error Messages and Solutions:

- **"Access denied for user"**: Check username/password and privileges in HeidiSQL
- **"Can't connect to MySQL server"**: Check if MariaDB service is running: `net start MariaDB`
- **"Table doesn't exist"**: Run the schema file to create tables
- **"System error 1067 has occurred"**: Service terminated unexpectedly - check Event Viewer
- **"Can't create/write to file"**: Check disk permissions and available space
- **"Port 3306 already in use"**: Another service is using the port - check with `netstat -an | findstr :3306`

### Windows Firewall Configuration:
```cmd
# Allow MariaDB through Windows Firewall
netsh advfirewall firewall add rule name="MariaDB" dir=in action=allow protocol=TCP localport=3306

# Remove rule if needed
netsh advfirewall firewall delete rule name="MariaDB"
```

### Log File Locations (Windows):
- **Error Log**: `C:\Program Files\MariaDB\data\hostname.err`
- **Slow Query Log**: Check my.ini configuration
- **General Log**: Check my.ini configuration
- **Windows Event Log**: Windows Event Viewer → Windows Logs → Application

### Configuration File (my.ini):
Typically located at: `C:\Program Files\MariaDB\data\my.ini`

Check these important settings:
```ini
[mysqld]
port=3306
basedir=C:/Program Files/MariaDB
datadir=C:/Program Files/MariaDB/data
character-set-server=utf8mb4
collation-server=utf8mb4_romanian_ci
```
